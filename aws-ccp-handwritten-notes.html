☁ Cloud Models

🏢
On-Premises
Traditional model
You own & manage hardware, datacenter, power, cooling, staff.
Cost: CapEx heavy — upfront hardware purchase
🔀
Hybrid Cloud
Mixed model
Combine on-prem + AWS cloud. Good for gradual migration or compliance needs.
Example: Use S3 for backup but keep DB on-prem
☁️
Full Cloud
AWS-only model
Everything runs on AWS. OpEx model — pay-as-you-go, no hardware.
Benefit: No CapEx, scale instantly, global reach

🌟 6 Benefits of Cloud Computing

💸
Trade CapEx → OpEx
Pay only for what you use. No upfront data center investment.
📦
Massive Economies of Scale
AWS aggregates usage from millions → lower pay-per-use prices.
↕️
Stop Guessing Capacity
Scale up or down in minutes. No over/under provisioning.
⚡
Increase Speed & Agility
Deploy in minutes. Experiment faster with lower cost of failure.
🏢
No Data Center Ops
Stop spending on racking, stacking, powering servers.
🌐
Go Global in Minutes
Deploy in multiple AWS Regions around the world with a few clicks.

🗺 AWS Global Infrastructure

🗺️
Regions
Physical location in the world with 2+ AZs. ~34 regions globally.
Example: ap-south-1 = Mumbai region
Exam tip: Not all services in all regions!
🏭
Availability Zones (AZ)
One or more discrete data centers with redundant power, networking. Each Region ≥2 AZs (usually 3).
Example: ap-south-1a, ap-south-1b, ap-south-1c
📡
Edge Locations / PoPs
Used by CloudFront CDN to cache content closer to users. 400+ edge locations globally. More than Regions!
Purpose: Reduce latency for end-users worldwide
🏘️
Local Zones
Extension of AWS Region in major metro areas. Single-digit ms response for latency-sensitive apps.
Example: Live video editing apps near end users

🔀 Shared Responsibility Model

⚠️ HIGH EXAM WEIGHT
Security and compliance is a SHARED responsibility between AWS and the customer.

☁ AWS Responsible (Security OF the Cloud)

  • Physical datacenter security
  • Hardware & global network
  • Hypervisor & host OS
  • Managed service software (RDS, Lambda runtime)
  • AZ/Region infrastructure

👤 Customer Responsible (Security IN the Cloud)

  • Guest OS patching (EC2)
  • Application code
  • IAM users, roles, policies
  • Data encryption (at rest & in transit)
  • Security Groups & NACLs config

⚙ Compute Services

🖥️
EC2
Elastic Compute Cloud
Virtual machines in the cloud. Full control over OS, storage, networking. Resizable compute capacity.
IaaSLinux / WindowsOn-Demand | Spot | Reserved
Exam: Host a .NET web app → EC2
Cheapest flexible: Spot Instances (~90% off!)
⚡
Lambda
Serverless Functions
Run code without provisioning servers. Pay per invocation. Auto-scales. Max 15 min timeout.
ServerlessEvent-DrivenFaaS
Example: S3 upload → Lambda → resize image → save
Tip: No server management = Lambda!
🫘
Elastic Beanstalk
PaaS deployment
Upload code → AWS handles deployment, load balancing, scaling, monitoring. Supports Node, Java, .NET, Python.
PaaSAuto-scaling
Exam: Deploy code without managing infra → Elastic Beanstalk
🐳
ECS / EKS / Fargate
Container Services
ECS = AWS-managed Docker. EKS = Managed Kubernetes. Fargate = Serverless containers (no EC2!).
DockerKubernetesFargate = Serverless
Exam: Containers without managing servers → Fargate
📈
Auto Scaling
EC2 Auto Scaling Group
Automatically add/remove EC2 instances based on demand. Maintains performance. Minimizes cost. Works with ELB.
Example: E-commerce — scale out during Diwali sale, scale in post-sale! 🪔
⚖️
Elastic Load Balancer
ELB
Distributes traffic across multiple EC2 instances.
ALB = HTTP/S, Layer 7
NLB = TCP, Layer 4
CLB = Legacy
Exam: Route by URL path → ALB

💾 Storage Services

🪣
S3
Simple Storage Service
Object storage. Unlimited storage. 99.999999999% (11 9s) durability. Files stored as objects in buckets.
ObjectsUnlimitedMax 5TB/obj
S3 Classes:
Standard → frequent access
Standard-IA → infrequent access
Glacier → archival, mins-hours retrieval
Deep Archive → cheapest, 12hr retrieval
💿
EBS
Elastic Block Store
Block storage for EC2. Like a hard drive attached to a VM. Persists independently from EC2 lifecycle. AZ-bound.
Block StorageEC2 onlyAZ-scoped
Exam: EC2 needs persistent storage → EBS
EBS snapshot = point-in-time backup in S3
📁
EFS
Elastic File System
Managed NFS file system. Shared across multiple EC2 instances and AZs simultaneously. Auto-scales.
Shared / Multi-AZLinux only
Exam: Multiple EC2s same file system → EFS (not EBS!)
❄️
S3 Glacier
Archive Storage
Low-cost archival. Data retrieval takes minutes to hours. Long-term backup/compliance data.
Instant: milliseconds (expensive)
Flexible: 1 min–12 hrs
Deep Archive: 12–48 hrs (cheapest!)
🌉
Storage Gateway
Hybrid storage connecting on-premises to AWS cloud storage. Bridge for migration or burst scenarios.
Exam: On-prem apps need cloud storage → Storage Gateway
🚚
AWS Snow Family
Physical devices to migrate large data to/from AWS when network is impractical.
Snowcone: 8 TB, portable, rugged
Snowball Edge: 80 TB, compute+storage
Snowmobile: 100 PB, literal truck! 🚛

🗄 Database Services

🗄️
RDS
Relational Database Service
Managed relational DB. Supports MySQL, PostgreSQL, MariaDB, Oracle, SQL Server, Aurora.
ManagedSQLMulti-AZ available
Exam: Managed SQL → RDS. High availability? → enable Multi-AZ
✨
Aurora
AWS-native relational DB
AWS proprietary. MySQL/PostgreSQL-compatible. 5x faster than MySQL, 3x than PostgreSQL. 6 copies across 3 AZs.
High PerformanceAuto-replicates
Exam: Highest performance AWS SQL → Aurora
⚡
DynamoDB
NoSQL Key-Value
Fully managed NoSQL. Single-digit millisecond performance at ANY scale. Serverless.
ServerlessNoSQLKey-Value
Exam: Serverless NoSQL, low latency, no fixed schema → DynamoDB
🧠
ElastiCache
In-Memory Cache
Managed Redis or Memcached. Ultra-low latency caching layer in front of databases. Reduces DB load.
Exam: Speed up DB queries / reduce latency → ElastiCache
📊
Redshift
Data Warehouse
Petabyte-scale data warehouse for analytics. OLAP workloads. Columnar storage. Integrates with QuickSight.
Exam: Analytics on large datasets → Redshift (NOT RDS!)
🔀
DMS
Database Migration Service
Migrate DBs to AWS. Supports homogeneous (Oracle→Oracle) and heterogeneous (Oracle→Aurora). Source stays live.
Exam: Migrate on-prem DB to RDS with minimal downtime → DMS

🌐 Networking & Content Delivery

🏗️
VPC
Virtual Private Cloud
Your private network in AWS. Logically isolated section. Control IP ranges, subnets, route tables, internet gateways.
Region-scopedSubnets per AZ
Public Subnet: Has internet access (via IGW)
Private Subnet: No direct internet access
Exam: Launch EC2 with no internet → Private Subnet
🛡️
Security Groups & NACLs
Security Group = Stateful firewall at EC2 instance level. Deny by default.
NACL = Stateless firewall at Subnet level. Processes rules in order.
Exam: Block specific IP at subnet level → NACL (not SG)
🌍
CloudFront
CDN
Content Delivery Network. Caches content at 400+ Edge Locations globally. Reduces latency. Integrates with S3, EC2, ALB.
Global CDNDDoS protection
Exam: Fast static content delivery globally → CloudFront
🧭
Route 53
DNS Service
Highly available DNS service. Domain registration, DNS routing, health checks. Routing policies: Simple, Weighted, Failover, Latency.
Exam: Map domain to EC2/ALB → Route 53
Failover to backup region → Route 53 health checks
🔌
Direct Connect
Dedicated private network connection from your data center to AWS. More reliable & faster than internet. Good for hybrid.
Exam: Dedicated, private, consistent bandwidth to AWS → Direct Connect (not VPN)
🔒
VPN
Site-to-Site VPN
Encrypted connection over public internet from on-prem to AWS VPC. Uses Virtual Private Gateway. Cheaper than Direct Connect.
Exam: Quick encrypted tunnel to AWS → VPN
Low cost, over internet
🔗
VPC Peering
Connect two VPCs privately. Traffic via AWS backbone (not internet). Can be cross-account or cross-region.
Note: Not transitive! A↔B and B↔C does NOT mean A↔C
🌐
Transit Gateway
Hub-and-spoke network model. Connect 1000s of VPCs and on-premises. Solves peering complexity at scale.
Exam: Many VPCs need to connect each other → Transit Gateway (not peering)

🔐 Security & IAM

👤
IAM
Identity & Access Management
Manage who can access what in AWS. Global service. Users, Groups, Roles, Policies. Least privilege principle.
GlobalLeast Privilege
Users: Individual people
Groups: Collection of users with shared permissions
Roles: For services (EC2, Lambda) or cross-account
Policies: JSON docs defining permissions
🕵️
GuardDuty
Threat Detection
Intelligent threat detection using ML. Analyzes CloudTrail, VPC Flow Logs, DNS logs. No agents needed.
Exam: Detect unusual API calls or crypto mining → GuardDuty
🔍
Inspector
Vulnerability Assessment
Automated security assessments for EC2 and container images. Checks for CVEs, network exposure, software vulns.
Exam: Find EC2 security vulnerabilities → Inspector
🛡️
Shield
DDoS Protection
Shield Standard: Free, automatic, protects all AWS customers
Shield Advanced: Paid, 24/7 DDoS response team, financial protection
Exam: DDoS protection → Shield. Advanced = 24/7 support
🌐
WAF
Web Application Firewall
Protects web apps from common attacks (SQL injection, XSS). Works with CloudFront, ALB, API Gateway. Define rules/ACLs.
Exam: Block SQL injection / XSS attacks → WAF
🗝️
KMS & Secrets Manager
KMS: Create & manage encryption keys for S3, RDS, EBS
Secrets Manager: Store, rotate, retrieve DB credentials & API keys. Auto-rotation!
Exam: Auto-rotate DB password → Secrets Manager
📋
CloudTrail
Audit Logging
Records ALL API calls in your AWS account. Who did what, when, from where. Stored in S3. 90-day default history.
Exam: Who deleted an S3 bucket? → CloudTrail
Compliance auditing → CloudTrail
⚙️
Config
Configuration Compliance
Tracks config changes to AWS resources. Evaluate against compliance rules. Timeline view of changes.
vs CloudTrail:
CloudTrail = API activity (who did what?)
Config = Resource state changes (what changed?)
🏢
Organizations & SCPs
Manage multiple AWS accounts centrally. Consolidated billing. SCPs = guardrails on member accounts.
Exam: Prevent accounts from using certain regions → SCP in Organizations

Estimate costs BEFORE you deploy. Build a scenario and get a cost breakdown. No AWS account needed.
URL: calculator.aws

Visualize, understand, and manage AWS costs over time. 12 months historical data. Forecast up to 12 months. Free!
Exam: Analyze past spend by service/account → Cost Explorer

Set custom cost/usage budgets. Get alerts when actual or forecasted costs exceed threshold. Up to 5 alerts/budget.
Exam: Email alert when spend exceeds $100 → AWS Budgets

Trusted Advisor
Real-time recommendations across 5 pillars: Cost Optimization, Performance, Security, Fault Tolerance, Service Limits.
Free: 7 checksBusiness+: All checks

Consolidated Billing
One bill for all accounts in AWS Organization. Volume discounts aggregated. Share Reserved Instances across accounts.
Exam: Single bill for multiple accounts → Consolidated Billing via Organizations

AWS Free Tier
Always Free: Lambda 1M req/mo, DynamoDB 25GB
12-Month Free: EC2 t2.micro, S3 5GB
Trials: Time-limited service trials
Exam: Lambda 1M req/month free → Always Free tier

Savings Plans
Up to 66% off. Commit to $/hour usage for 1-3 years. Works for EC2, Lambda, Fargate. More flexible than Reserved Instances.
Compute Savings Plan: Most flexible, any region/family
EC2 Savings Plan: Specific family, ~72% off
🏷️
Cost Allocation Tags
Tag resources (Project=X, Dept=Eng) to track costs by team/project. Must activate in billing console first!
Exam: Track costs per project/department → Cost Allocation Tags

CloudWatch
Monitoring & Alerts
Collect metrics, logs, events from AWS services. Create dashboards, set alarms. Can trigger Auto Scaling.
Metrics: CPU, memory, network
Logs: App logs, Lambda logs, VPC Flow logs
Alarm: SNS notification when threshold breached

Infrastructure as Code
Define AWS infrastructure using JSON/YAML templates. Provision and update resources consistently. Stacks = group of resources.

Messaging
